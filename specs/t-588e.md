Done means: the fast gate is green and the feature is visible in the profile dev command

## Problem

Manage Results prints **Category** as a group heading and again as the `category` field heading. `npm run build` fails with TS6133 because `_status` is written but never read.

## In scope

- Results shows the word Category once. Values from a `category` field sit under that heading with no second Category row.
- Other category fields (status, source, …) may still have their own subheads under Category.
- Remove unused `_status` so `tsc` / `npm run build` succeeds.
- Tests cover a single Category heading when the scan has `category:…` pairs.
