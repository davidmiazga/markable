## Problem

Markable Backlinks already shows a hover popover for wiki-links when that plugin is on. It does not preview other internal links, and it does not use the Ctrl/Cmd hover rule in the editor. Do not start until diary ticket t-4c2d is accepted.

## UX / behavior
Any links are visually styled and the user can hover. However, if Ctrl/Cmd is pressed a preview of the page appears in a small window (like a tooltip). The preview should be big enough that the text, esp the title can be read.
