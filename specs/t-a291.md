# Replace the Wrangler sidebar dump with a settings-like tag manager

Done means: the fast gate is green and the feature is visible in the profile dev command
Writes: src/, src-tauri/src/, index.html, flavors/, scripts/, src-tauri/tauri.conf.json, planning/, tests/
Dev: cd . && npm run tauri dev

## Problem

The Properties Wrangler sidebar crams scan controls, checkboxes, and an Add button into a 150px-minimum rail. Users cannot tell what the rows do, the Add button clips to “A”, Tags can appear twice, and similar-tag consolidate is easy to miss.

## In scope

- Sidebar is a short explanation plus a full-width **Manage tags…** button. No checkbox list, no Add, no three-button toolbar in the rail.
- **Manage tags…** opens a settings-like sheet (overlay + labeled sections, Escape / backdrop / × close).
- Sheet copy states that a checked tag is offered in File Properties chips and that notes are not rewritten.
- Scan / Choose folder / Open properties file live in the sheet as full-width labeled actions.
- Tags section is rendered once. Skip a category field whose key is `tags`.
- **Similar tags** consolidate UI appears only when `nearDupClusters` finds members. Hidden when there are no lookalikes.
- No horizontal scroll at the sidebar min width: wrap text, stack actions, `overflow-x: hidden`.
- Add control (in the sheet only) is labeled **Add to offer list**, never a lone “A”.

## Out of scope

- Drag-and-drop parent/child tag trees (later).
- Rewriting tags inside note files (still next).
