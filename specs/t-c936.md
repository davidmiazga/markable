# Add multi-column layouts and callout background colors to notes, callout cells, and HTML/PDF export.

Done means: the fast gate is green and the feature is visible in the profile dev command
Writes: src/, src-tauri/src/, index.html/, flavors/, scripts/, src-tauri/tauri.conf.json/, planning/, tests/
Dev: cd . && npm run tauri dev

## Problem
Notes need prebuilt multi-column layouts and customizable callout background colors that work cleanly across live preview, column cells, and HTML/PDF export without requiring fragile raw HTML/CSS mixing.

## In scope
- **Multi-column layouts (`/columns` + `columns` / `columns-card` fences):**
  - Support `columns` and `columns-card` fenced blocks (alongside `grid` / `grid-card`), where the first line optionally declares column count (`2`, `3`, `4`, or `NxM` dimensions; defaults to `2` columns for `columns` and `3x3` for `grid`) and `---` separates each column's Markdown content.
  - Add `/columns` to the slash-command palette with sub-options (`2 columns`, `3 columns`, `4 columns`, `2 card columns`, `3 card columns`) and register `Columns: 2 Columns` / `Columns: 3 Columns` in the command bar / Format menu.
  - Support `wide` and `full` width modifiers on `columns` and `columns-card` fences (` ```columns wide `, ` ```columns-card full `).
- **Callouts inside columns and grids:**
  - Ensure `> [!type]` callouts (including `plain-<color>` and custom background colors) placed inside `columns`, `columns-card`, `grid`, `grid-card`, and `sidebar` cells are converted with `convertCalloutsToHtml` before `marked` parses cell Markdown, so callout boxes and background colors render properly inside columns.
- **Callout background colors (`bg` metadata + palette):**
  - Support background color overrides on any callout via pipe metadata in the header (`> [!note|bg-blue] Title`, `> [!tip|yellow] Title`, or `> [!plain|#2ea043] Title`) in addition to the existing `> [!plain-<color>]` shorthand.
  - Expose all `plain-<color>` background callout commands (`Callout: Plain Blue`, `Cyan`, `Green`, `Yellow`, `Orange`, `Red`, `Purple`) in the command bar / keybindings panel so they match the `/callout` → `plain` slash picker.
- **HTML & PDF export parity:**
  - Convert `columns`, `columns-card`, `grid`, `grid-card`, and `sidebar` / `sidebar-left` fences into styled multi-column / card HTML in `export.ts` (instead of raw `<pre><code class="language-...">` blocks) so exported HTML and US Letter PDFs preserve columns and callout backgrounds.

## Out of scope
- Freeform drag-to-resize column dividers inside the editor.
- Arbitrary raw HTML layout builders or WYSIWYG nested sub-editors inside cells.
- Changing how `select` dashboard blocks or YAML front matter work.

## UX / behavior
- Typing `/columns` at the start of a line opens a sub-picker for `2`, `3`, `4`, `2-card`, or `3-card` columns, inserts the `columns` fence with `---` column separators, places the cursor in column 1, and enters preview mode when moving off the block.
- Pressing `Escape` while typing `/columns` removes the typed slash text and closes the menu (matching `/grid` and `/sidebar`).
- A column cell containing `> [!plain-blue]` or `> [!note|purple]` renders as a tinted callout box inside that column in both live preview and exported HTML/PDF.
- Any callout with a color modifier (`> [!warning|red]`, `> [!plain-green]`, or `> [!quote|#f0b429]`) tints its background and border using that color token in both the editor and exports.

## Tests
- `parseCalloutHeader` parses optional `|<color>` / `|bg-<color>` / `|#hex` background metadata while preserving canonical type, fold marker (`+`/`-`), title, and nesting depth.
- Live preview and `markdownToHtml` render `columns` / `columns-card` / `grid` / `grid-card` blocks as multi-column CSS grids and render nested callouts (including tinted backgrounds) inside column cells.
- Slash command `/columns` is registered, opens its column-count sub-picker, inserts the expected `columns` fence, and cleans up typed text on `Escape`.
- Exported standalone HTML and PDF HTML include column grid styles and callout background color rules rather than raw `<pre><code>` blocks.
