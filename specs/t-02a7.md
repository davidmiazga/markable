Later: Expand / collapse same-level nested tags

The caret on a nested tag opens or closes only that one branch. There is no way to open or close every sibling at the same depth together.

## In scope
In Manage, shift-click the caret of a tag that has children. That expands or collapses every tag at the same depth in that section, including the one you clicked. A plain click still toggles only that one branch.

## Out of scope
Categories keep the same caret behavior they have now, unless the row is a nested tag. Drag-drop, rename, merge, and search are unchanged. The file tree in the file browser is unchanged.

## UX / behavior
A plain click on a caret still toggles that branch only. Shift-click collapses every sibling at that depth when any of them is open, and expands them all when all of them are collapsed. A tag with no children does nothing. While the Manage search box has text, the tree stays fully expanded, as it does today.

## Tests
Run the usual cargo and vite checks. Build a tree with two siblings that each have a child. Assert a plain click toggles one branch. Assert a shift-click collapses both, and a second shift-click expands both.
