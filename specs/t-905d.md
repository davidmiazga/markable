# Add a footer trash icon that shows whether the queue is empty and opens Finder or Data Protection settings.

Done means: the fast gate is green and the feature is visible in the profile dev command
Writes: src/, src-tauri/src/, index.html, flavors/, scripts/, src-tauri/tauri.conf.json, planning/, tests/
Dev: cd . && npm run tauri dev

## Problem
An option is needed in these settings that will allow a trash icon in the footer menu. This icon (when the preference is set to 'show trash icon') will be a closed can when nothing is in the trash queue, and a full/open top can when there IS a queue. Also clicking on the icon shows the files in the finder. Ctrl/Cmd-click takes us to these file protection settings directly.

## In scope
All functions to accurately hide/show this icon when each setting has been selected in settings. Shortcuts and functions should work.

## Out of scope
Do not change other plugins or settings. Just this file protection setting needs these additions. 
## UX / behavior
User should be able to open/change settings. Based on selection, the app accurately hide/shows this trash icon when each setting has been selected in settings. Shortcuts and functions should work (clicking, Cmd-clicking).

## Tests
All the usual tests (ts, cargo, etc.). Add a test for making sure the settings show the icon in the UI and the icon is clickable/Cmd-clickable.
