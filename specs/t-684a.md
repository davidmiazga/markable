# Lock or unlock panel positions and save or restore named Workspace Panel-Locations presets.

Done means: the fast gate is green and the feature is visible in the profile dev command
Writes: src/, src-tauri/src/, index.html/, flavors/, scripts/, src-tauri/tauri.conf.json/, planning/, tests/
Dev: cd . && npm run tauri dev

## Problem
Once users can drag and dock panels across Left, Right, Top, and Bottom areas, accidental header drags or resizes can mess up their layout, and there is no way to save or switch between named panel-location arrangements ("Workspace Panel-Locations").

## In scope
- **Lock / Unlock Panel Positions (`sidebar.locked`):**
  - Add `locked?: boolean` to `SidebarSettings` (default `false`).
  - When `locked` is `true`, disable panel header drag-to-move/reorder, hide or disable `.sidebar-move-btn`, and disable dock resize handles, while still allowing panels to expand/collapse (accordion toggle), switch tabs, and show/hide docks.
  - Expose `Lock Panel Positions` (`sidebar.toggleLock`) in the View menu (`menu.rs`), Command Bar (`keybindings-panel.ts`), and panel header right-click context menu.
- **Saved Workspace Panel-Locations presets (`sidebar.savedPanelLocations`):**
  - Store named presets in `SidebarSettings.savedPanelLocations` where each preset records `{ name, panelSides, slots: { left, right, top, bottom } }` (open state, size, panelOrder, accordion/pin state).
  - Add a **Workspace Panel-Locations** section/control (accessible via Command Bar commands `Panel Locations: Save Current…`, `Panel Locations: Reset to Default`, and switching/deleting saved presets in Settings and panel header context menu).
  - `Reset to Default Panel Locations` restores all panels to their plugin-default Left/Right sides, resets slot sizes, and closes Top/Bottom docks.

## Out of scope
- Changing which plugins are enabled/disabled (reserved for the separate "Workspaces" concept).
- Cloud syncing panel-location presets across machines.

## UX / behavior
- Toggling **Lock Panel Positions** prevents dragging headers, clicking the dock-move icon, or dragging resize handles; unlocking restores full drag/move/resize behavior.
- Saving a Workspace Panel-Locations preset prompts for a name and saves the current 4-dock arrangement to settings.
- Selecting a saved preset immediately moves all panels to their saved docks (`left`/`right`/`top`/`bottom`), restores each dock's open/closed state and size, and persists the active arrangement.
- Choosing **Reset to Default Panel Locations** returns every panel to its default Left/Right sidebar and hides Top/Bottom.

## Tests
- When `sidebar.locked` is `true`, pointer drag on `.sidebar-panel-drag-handle`, `.sidebar-move-btn`, and `.sidebar-resize-handle` are inert, while `.sidebar-accordion-toggle` still expands/collapses.
- Saving a Workspace Panel-Locations preset captures `panelSides` and all four slot states; applying that preset after moving panels restores their dock sides, order, open states, and dimensions.
- Resetting to default clears `panelSides` overrides, returns panels to Left/Right, and hides Top and Bottom docks.
- Deleting a saved Workspace Panel-Locations preset removes it from settings without affecting the active layout.
