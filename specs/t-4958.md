# Dock panels to Left, Right, Top, or Bottom via drag-and-drop and a 4-way dock icon, keeping Left and Right as the default.

Done means: the fast gate is green and the feature is visible in the profile dev command
Writes: src/, src-tauri/src/, index.html/, flavors/, scripts/, src-tauri/tauri.conf.json/, planning/, tests/
Dev: cd . && npm run tauri dev

## Problem
Panels can only live in the Left or Right sidebars and use a left-right arrow (`⇄`) button. Users need to be able to dock panels into Top and Bottom pane areas as well (while keeping Left and Right as the default), using either drag-and-drop or a 4-way dock selector icon.

## In scope
- **Four dock slots (`left`, `right`, `top`, `bottom`):**
  - Keep `left` and `right` as the default dock sides for all plugins. `top` and `bottom` dock slots start empty and hidden (`display: none`) until a panel is moved into them.
  - Mount `#sidebar-top` above the editor and `#sidebar-bottom` below the editor inside the center column (between `#sidebar-left` and `#sidebar-right`), with vertical height resize handles (`120px`–`450px`, default `200px`) and horizontal side-by-side panel layout when multiple panels share `top` or `bottom`.
- **Replace the `⇄` button with a dock position icon + 4-way menu:**
  - Replace the literal `⇄` text in `.sidebar-move-btn` with an inline SVG dock-position icon.
  - Clicking `.sidebar-move-btn` opens a compact popover menu with `Left`, `Right`, `Top`, and `Bottom` options (highlighting the current side) and moves the panel to the chosen dock.
- **Cross-dock drag-and-drop:**
  - Extending panel header drag (`panel-reorder-drag.ts`): dragging a panel header shows drop-zone indicators for `Left`, `Right`, `Top`, and `Bottom` dock edges in addition to reordering within the current dock. Dropping onto another dock edge moves the panel to that dock and opens it.
- **Plugins detail view & View toggles:**
  - Update the Plugins detail view (`plugins-panel.ts`) position buttons from `Left | Right` to `Left | Right | Top | Bottom`.
  - Add `Toggle Top Dock` and `Toggle Bottom Dock` commands (`sidebar.toggleTop`, `sidebar.toggleBottom`) to `keybindings-panel.ts` and `main.ts`.

## Out of scope
- Locking/unlocking panel positions and saving/restoring named Workspace Panel-Locations presets (covered in `t-684a`).
- Floating undocked OS windows.

## UX / behavior
- Fresh launch looks identical to today: only Left and Right sidebars are used by default; Top and Bottom docks are hidden when empty.
- Clicking the dock icon on any panel header lets the user pick `Left`, `Right`, `Top`, or `Bottom` (or `movePanel(id)` programmatic calls still work).
- Dragging a panel header within its current dock reorders it; dragging it to the Left, Right, Top, or Bottom edge highlights the target dock zone and moves the panel there on drop.
- Dock assignments (`panelSides`), open state, active tab, panel order, and slot size (`width` for left/right, `height` for top/bottom) persist in settings across restarts.

## Tests
- `SidebarManager` creates `#sidebar-left`, `#sidebar-right`, `#sidebar-top`, and `#sidebar-bottom` slots, keeping empty `top` and `bottom` hidden on init and restore.
- `movePanelToSide(panelId, "top" | "bottom" | "left" | "right")` moves the panel DOM wrapper to the target slot, opens the slot, and persists `panelSides[panelId]`.
- Clicking `.sidebar-move-btn` opens the 4-way dock picker and selecting `Top` or `Bottom` moves the panel there; vertical resize on `top`/`bottom` clamps height to `[120, 450]`.
- Plugins panel detail view renders `Left`, `Right`, `Top`, and `Bottom` buttons and updates the active button when clicked.
