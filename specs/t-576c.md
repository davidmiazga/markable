## Problem
Make Project’s board the note-based folder-view kanban. Remove the settings-card sidebar board so there is one kanban. Stop for a check-in when this phase is done.

**Project.** [kanban.plugin.ts](markable/src/plugins/kanban/kanban.plugin.ts) stores cards in plugin settings, not in notes. The real board is the folder-view kanban. The Project sidebar should be that board over notes, or the settings-card plugin should be dropped so the app does not ship two kanbans.

## In scope
Just this plugin so it works like a typical kanban board. Reference Asana and/or Folia Obsidian plugins.

## Out of scope
Do no change the apps core behaviors.

## UX / behavior
When a user opens a specific file marked as kanban board/view, they have a file that has columns (customizable) to store their tasks (horizontal scroll). These tasks can change columns (yaml), which are other .md files that represent tasks (which can have more yaml data to further organize the task on the board). Those tasks can have subtasks. Each task or subtask has a name or title, with a file name, title name, a status (linked to where it shows as a column/lane), Priority, Due date, Asignee, custom value pairs, description, tags, subtasks, items - simple checkboxes, a linked card to set as a 'blocker', Comments, History(collapsable). The lanes can be minimized, hidden. The Lanes can have a color (just a dot and border top). The card can have a color, color border or both. They should be able to toggle title, tags, a line of tasks or subtasks that shows how many are done (5/15, etc). Each lane has a number in the upper right with the amount of cards in it. A '+' somewhere in the lane (bottom) that lets the user easily add a card. At the top, we should have a search function, and some filters (overdue, due soon, blocked, unread, etc).
