## Overview

This step initializes a **new Tauri v2 project** using the official `npm create tauri-app` scaffolding command with the **vanilla TypeScript template and Vite**. The result is a working dev environment where the frontend (TypeScript) communicates with the Tauri backend (Rust) via command IPC.

**Output:** A fully initialized Tauri v2 project with correct dependency versions, strict TypeScript configuration, and Vite optimized for development.

### Task 1.3: Configure tsconfig.json for Strict Mode

The scaffolding creates a default tsconfig.json, but it must be explicitly configured for strict compilation. **Overwrite** the file with this exact configuration:

**File: `tsconfig.json`**

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "useDefineForClassFields": true,
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "skipLibCheck": true,
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true,

    "strict": true,
    "noImplicitAny": true,
    "noImplicitThis": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noImplicitReturns": true,
    "noFallthroughCasesInSwitch": true,

    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "resolveJsonModule": true,
    "declaration": true,
    "sourceMap": true,
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src/**/*.ts", "src/**/*.tsx"],
  "exclude": ["node_modules", "dist", "src-tauri"]
}
```

**Key settings:**
- `"strict": true` — Enables all strict type checking options
- `"noImplicitAny": true` — No implicit `any` types
- `"noUnusedLocals": true, "noUnusedParameters": true` — Catch dead code
- `"noImplicitReturns": true` — All code paths must return a value
- `"target": "ES2022"` — Modern JavaScript features (async/await stable)
- `"module": "ESNext"` — Uses ES modules
- `"moduleResolution": "bundler"` — Works with Vite's bundling strategy

**Verify:**

```bash
npx tsc --noEmit
```

This should produce **zero errors** and **zero warnings**. If it fails, the tsconfig.json is incorrect.

## Troubleshooting

### Issue: npm install fails with "permission denied"

**Solution:**
```bash
sudo chown -R $(whoami) ~/.npm
npm install
```

### Issue: npm run tauri dev hangs or times out

**Solution:**
1. Kill any existing Tauri processes: `pkill -9 tauri`
2. Clear Vite cache: `rm -rf node_modules/.vite`
3. Retry: `npm run tauri dev`

### Issue: TypeScript errors appear in tsc --noEmit

**Solution:**
1. Verify tsconfig.json strict settings are applied
2. Run `npm install @types/node` if Node.js types are missing
3. Check for any implicit any types in source files

### Issue: Vite port 1420 already in use

**Solution:**
```bash
# Find process using 1420
lsof -i :1420

# Kill it
kill -9 <PID>

# Retry
npm run tauri dev
```
