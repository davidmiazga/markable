# Quickstart

Welcome to **Markable** — a clean, distraction-free Markdown editor for macOS.

---

## Opening & Saving Files

| Action | Shortcut |
|---|---|
| New file | Cmd-N |
| Open file | Cmd-O |
| Import (.md / .txt) | Cmd-Opt-I |
| Save | Cmd-S |
| Save As | Cmd-Shift-S |
| Export as HTML | Cmd-Opt-E |
| Close | Cmd-W |

---

## Live Preview

Markable uses a **Typora-style live preview**: Markdown syntax is visible while your cursor is on a line and hides when you move away. What you see is close to the final rendered output — no split-pane required.

---

## Basic Formatting

| Format | Shortcut |
|---|---|
| Bold | Cmd-B |
| Italic | Cmd-I |
| Underline | Cmd-U |
| Strikethrough | Cmd-Shift-X |
| Highlight | Cmd-Shift-H |
| Superscript | Cmd-Shift-6 |
| Subscript | Cmd-Shift-9 |
| Inline math | Cmd-Shift-M |

| Format | Shortcut |

| Task list | Opt-X |

| Code fence | Opt-C |
| Horizontal rule | Opt-/ |
| Indent | Cmd-] |
| Outdent | Cmd-[ |

## Inserting Elements

| Action | Shortcut |
|---|---|
| Insert link | Cmd-K |
| Insert image | Cmd-Shift-I |
| Insert table | Cmd-Shift-T |

---

## Themes

Switch themes from the **Theme** menu or with keyboard shortcuts:

- **Next theme:** Ctrl-Shift-↓
- **Previous theme:** Ctrl-Shift-↑

To create your own theme, see **Help → Help** for a step-by-step walkthrough.

---

## Find & Replace

- **Find:** Cmd-F
- **Find and Replace:** Cmd-Opt-F

The Find bar floats on screen and can be dragged anywhere. Press **Esc** to close it.

---

## Settings

Open **Settings** with **Cmd-,** to adjust content width, font size, and default theme.

---

*For the full keyboard shortcut reference and theme authoring guide, open **Help → Help**.*
